# 音楽ファイルを整理

選択した音楽ファイルを、タグをもとに表示中のフォルダの中の `アルバムアーティスト/アルバム/` へ移動します。

## 入れ方

このフォルダ（`organize-music`）ごと `~/Library/Application Support/Ommateum/plugins/` にコピーします。
初めて実行したときに `organize.swift` をコンパイルするので、Xcode かコマンドラインツール（`xcode-select --install`）が必要です。初回だけ数秒かかります。

## 動作

- 対象: mp3 / m4a / m4b / aac / flac / alac / wav / aif / aiff / aifc / caf。選択したものが**すべて**これらのファイルのときだけメニューに出ます。
- フォルダ名
  - アーティスト: アルバムアーティスト（ID3 の TPE2、iTunes の aART、FLAC の ALBUMARTIST）。なければアーティスト、それもなければ「不明なアーティスト」
  - アルバム: アルバム名。なければ「不明なアルバム」
  - `/` と `:` は `_` に置き換え、先頭の `.` も `_` にします（隠しフォルダにならないように）。
- 移動先に同じ名前のファイルがあれば、上書きせず「曲 2.mp3」のように番号を付けます。
- すでに正しい場所にあるファイルは動かしません。
- 読めないファイル（拡張子だけ音楽のファイルなど）はスキップし、最後に件数と名前を表示します。
- タグの読み取りは macOS の AVFoundation を使います。ogg / opus などは対象外です。
- Ommateum の「取り消す」では元に戻せません。
