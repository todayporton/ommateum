- **[判断]** Finder の Dropbox メニューは流用しない — Finder Sync 拡張のメニューは他のアプリから呼ぶ公開手段がない（`docs/feasibility.md` 2節）
- **[指示]** 「コピーを転送」は使えるようにする。**[判断]** Dropbox の共有拡張を直接実行して実現 — この拡張だけは公開の仕組みで呼べる（b0dba7d）
- **[指示]** こうした連携はプラグインのように追加できる構成にする。**[判断]** `FileActionProvider` と `actions.json` を用意 — ブラウザやメニューのコードを触らず、再ビルドなしでも足せるように（b0dba7d）
- **[指示]** 残りのフェーズを最後まで実装（56616f9〜ec008be）
- **[判断]** Release ビルドで Swift オプティマイザがクラッシュするので回避を入れた（34fa4fa）
- **[判断]** カラム表示の名前変更は入力欄を行に重ねる方式 — `NSBrowser.editItem` が編集を開始しない（ec008be）
- **[指示]** 選択をマウスアップでなくダウンで行う — Finder に合わせる（cb1b20a）
- **[指示]** ウインドウ外へ出したタブを戻せるようにする。**[判断]** ウインドウが複数あるときは1タブでもタブバーを出す — タブバーが唯一の掴む場所のため。ウインドウ統合コマンドも追加（cb1b20a）
- **[指示]** ドロップ時にカーソルの上のフォルダが光る不具合を修正、登録ワークスペースをサイドバー最下部に一覧（cb1b20a）
- **失敗:** 自動 UI テストのタブドラッグが実ファイルの行に落ち、ホームの実在のフォルダを移動した（すぐ復元）。座標クリックが別のアプリに届く事故も2回 — 以後は検証用フォルダと `OMMATEUM_SUPPORT_DIR` を使い、イベントごとに対象ウィンドウ内か確認するツール経由で操作する

## 2026-10-31 サイドバーと外観

- **[指示]** マウスのサイドボタンで戻る/進む（6f54ad5）
- **[指示]** Finder 風の「場所」と設定での表示切り替え、サーバーをサーバー名でまとめる（2164f51, e0cab53）
- **[指示]** サイドバーの仕様を Finder ではなく QSpace に合わせる。任意名のグループを複数作れて、「場所」は「ドライブ」に改名。サーバーは1台でも階層表示（a4aabb7）
- **[指示]** 未接続の登録サーバーを取得できないならアプリ内で接続を追加できるようにする。**[判断]** マウント中の共有を `volumeURLForRemounting` から自動登録し、未接続でも残す — Finder の一覧を読む公開 API がない（a4aabb7）
- **[指示]** 取り出しアイコンの縮小とホバー表示、グループ内の字下げをなくし、共有の字下げを小さく（64cfbaa, e1bff20, 41d5662）
- **[指示]** VS Code のように、サイドバーと各ペインを隙間と角丸のあるカードにする（599343d）
- **[指示]** ウインドウ角丸を VS Code のように小さく。`UIDesignRequiresCompatibility` の採用はユーザー決定 — macOS 26 の大きい角丸を避ける公開の設定。同時に明るすぎるサイドバーの色を抑えた（cfe71b8）
- **[指示]** 隙間と窓の境をはっきりさせるため背景を暗くし、黒すぎるとの指摘で少し戻した（6ed1e42, 9eaa067）
- **[指示]** サイドバーのハイライトを控えめにし、空白クリックで外れないようにする。一覧の縞を角丸に（faecbca）
- **[指示]** 試しにサイドバーを背景と同色・縁なしにし、そのまま採用。一覧と縞の余白、取り出しと残容量の位置を調整（8401c9c, 882afe4）
- **[指示]** アクティブなペインは上辺だけでなく全周を色付け（f0e63e8）
- **[指示]** リネーム後に選択とフォーカスを保つ（711aea0）
- **[指示]** サイドバーの行の寸法と、アクティブ/非アクティブの色を Finder に合わせる。**[判断]** 色は Finder の実測値を使い、非アクティブは半分の強さで描く（cae3fe2, 6dbb798）
- グループ名クリックで文字が大きくなる不具合を修正（8ae48fa）
- **[指示]** 開閉 chevron を右へ（サーバーは常時表示、テキストと同色）、表記を「サーバー」に、取り出しは共有のみに。**[判断]** 折りたたみは子の数を0にするデータ方式 — NSOutlineView は標準の三角がない行を畳めない（37a8409）
- **[指示]** 閉じたサイドバーはアイコン幅にし、ホバーで元の幅を重ねて表示。開閉とホバーにアニメーション、ファイルドラッグでも広がる。**[判断]** サイドバーを分割ビューの上の層に置く — ペインを動かさず重ねるため（791508f, 053a65c）
- **[指示]** 重なった状態でも幅を変更可能に、グループ名はフェード。ドラッグでハイライトされないことがある不具合と、ドロップ後にハイライトが残る不具合を修正。**[判断]** ドロップのハイライトは自前で描画（b993d8e, 4462513）
