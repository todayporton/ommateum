## Finder との差異（既知）

- カラム表示では、空白ダブルクリック・ファイルのドラッグ＆ドロップに未対応。名前変更はシートで行う。
- 取り消し／やり直しで名前が変わった項目は、選択状態が維持されない。
- 置き換え時に既存項目をゴミ箱へ移す（Finder は削除）。
- 選択した項目に自分自身を含むコピー（例: フォルダを、そのフォルダ自身へ貼り付け）は全体を中止する（Finder は該当項目のみエラー）。
- 検索、ギャラリー表示、グループ化、タグ編集、情報を見る、エイリアス作成は未実装。

## 開発中に修正した主な不具合（再発防止のため記録）

- フォルダURLの末尾 `/` や `/private/tmp`↔`/tmp` の表記差で URL 比較が一致しない → 比較はパス基準、一覧の URL は要求フォルダから組み立てる（テストあり）。
- 非同期処理の完了後に Undo を登録すると、取り消しの逆操作が Redo でなく Undo に積まれる → 開始時に同期登録。
- 分割比率を初回レイアウト時に一度だけ適用していたため再起動ごとにずれる → リサイズ時は常に比率で配置。
- NSBrowser の未ロード列へのアクセスで例外 → 列範囲を必ず確認。
- タブボタンの必須制約が幅0で矛盾 → 優先度を下げる。
