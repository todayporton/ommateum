# プラグイン（plugins フォルダ）

1つのプラグインは1つのフォルダです。フォルダを置くだけで、右クリックメニューと「ファイル ▸ アクション」にコマンドが加わります。アプリの再ビルドは不要です。

- 場所: `~/Library/Application Support/Ommateum/plugins/<プラグインのフォルダ>/`
  （「設定 ▸ プラグイン ▸ プラグインフォルダを開く」または「ファイル ▸ アクション ▸ プラグインフォルダを開く」で開けます。フォルダがなければ作ります）
- フォルダを追加・削除したり `plugin.json` を保存したりすると、次にメニューを開いたときから反映されます。
- 「設定 ▸ プラグイン」に読み込んだプラグインが並び、チェックで有効・無効を切り替えられます。新しく置いたプラグインは有効の状態で始まります。
  有効・無効はフォルダ名で覚えるので、フォルダ名を変えると有効に戻ります。
- `plugin.json` がない、または書式が壊れているプラグインも一覧に出て、原因を赤字で表示します。有効のままなら、メニューにも「プラグイン「…」を読み込めません…」が出ます。

## フォルダの構成

```
plugins/
  zip/
    plugin.json
    zip.sh
```

## plugin.json

```json
{
  "version": 1,
  "name": "ZIP に圧縮",
  "description": "選択項目を1つの ZIP にまとめます",
  "actions": [
    {
      "title": "ZIP に圧縮",
      "type": "script",
      "command": "zip.sh",
      "arguments": ["{files}"],
      "shortcut": "ctrl+cmd+z"
    }
  ]
}
```

| キー | 必須 | 内容 |
| --- | --- | --- |
| `version` | | 書式の版。今は `1` |
| `name` | ✓ | 設定の一覧に出す名前 |
| `description` | | 設定の一覧に出す説明 |
| `actions` | ✓ | アクションの配列。各項目の書式は [actions.md](actions.md) と同じ |

`actions.json` との違いは、`script` の `command` の探し方だけです。

- `/` や `~` で始まるパス: そのまま使う
- `zip.sh` や `bin/tool` のような相対パス: プラグインのフォルダの中を探す。`/` を含まない名前でフォルダにないもの（`open`、`python3` など）は PATH から探す
- フォルダの中のファイルには実行権限が必要です。ない場合はエラーを表示します（`chmod +x zip.sh`）

スクリプトの作業ディレクトリは表示中のフォルダです。プラグイン自身のフォルダのパスは環境変数 `OMMATEUM_PLUGIN_DIR` に入ります。

## zip.sh の例

```zsh
#!/bin/zsh
# 選択項目を「アーカイブ.zip」にまとめる（作業ディレクトリは表示中のフォルダ）。
# ${@:t} は各引数のファイル名部分。ZIP の中にフルパスが入らないようにする。
/usr/bin/zip -r -q "アーカイブ.zip" "${@:t}"
```

## 読み込みと安全性

プラグインのコードをアプリの中に読み込むことはしません。スクリプトは別のプロセスとして、ショートカットは `shortcuts` コマンドで、共有サービスは macOS の共有拡張として実行します（理由は [architecture.md](architecture.md) の「拡張」）。
それでもスクリプトはあなたの権限で動くので、中身を確かめたプラグインだけを置いてください。
