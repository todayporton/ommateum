# Ommateum

[English](README.md) | 日本語

複数のフォルダを同時に見渡すための、macOS ネイティブのファイラーです。
Finder の使用感をできるだけ保ったまま、次の3点を加えています。

1. 一覧の**空白部分をダブルクリック**すると親フォルダへ移動
2. VS Code のエディターグループのように、**タブのドラッグでペインを縦横自由に分割・再配置**（ペインごとに独立したタブを持つ）
3. 画面構成・フォルダ・タブを**名前付きワークスペース**として保存・復元

画面は英語と日本語に対応しています。システムの言語に従い、設定 ▸ 一般 ▸ 言語 でこのアプリだけの言語（システム、English、日本語）を選べます。

## ビルド

- 要件: macOS 14 以降、Xcode 16 以降（確認環境: Xcode 26.6 / macOS 26.2 / Apple Silicon）
- 外部ライブラリなし

```sh
open Ommateum.xcodeproj            # Xcode で ⌘R
# またはコマンドライン
xcodebuild -project Ommateum.xcodeproj -scheme Ommateum -derivedDataPath build build
xcodebuild -project Ommateum.xcodeproj -scheme Ommateum -derivedDataPath build test
open build/Build/Products/Debug/Ommateum.app
```

Bundle ID は `online.todayporton.ommateum` です。
App Sandbox は使っていません（理由は [docs/feasibility.md](docs/feasibility.md) §5）。

設定・セッション・ワークスペースは `~/Library/Application Support/Ommateum/` に JSON で保存されます。
環境変数 `OMMATEUM_SUPPORT_DIR` で別の場所を指定できます（実データに触れずに UI を試すとき用）。

## ウインドウとワークスペース

- **Dock メニュー**: 開いているウインドウを `[ワークスペース名] - フォルダ | フォルダ`（ペインごとのフォルダ）の形で並べ、その下にワークスペースの一覧と「新規ウインドウ」を出します。開いているワークスペースを選ぶと、そのウインドウが前面に出ます。
- **新規ウインドウ**（設定 ▸ 一般 ▸ 新規ウインドウ）: 新しいウインドウは、前回のウインドウ（前面のウインドウ、なければ最後に閉じたウインドウ）か、保存したウインドウを元にします。引き継ぐ項目（レイアウト・位置・サイズ・ディスプレイ）と、ディスプレイを引き継がないときに開く画面（マウスカーソルのある画面 / 前面のウインドウがある画面）を選べます。
- **ワークスペース**（ワークスペース ▸ ワークスペースを管理…）: ワークスペースごとに、開くときに保存時の位置・サイズ・ディスプレイを復元するかと、復元しないときに開く画面を選べます。

## URL スキーム

ランチャーやショートカット、リンクから、次の URL で Ommateum を開けます。

| URL | 開くもの |
| --- | --- |
| `ommateum://open` | 新規ウインドウ（設定 ▸ 一般 ▸ 新規ウインドウ に従う） |
| `ommateum://open?path=~/Documents` | そのフォルダを新規ウインドウで。ファイルなら、そのフォルダを開いてファイルを選択 |
| `ommateum://workspace?name=作業` | そのワークスペースのウインドウ。開いていなければ新規ウインドウで開く |

フォルダやサイドバーのワークスペースの右クリックメニューにある「URLをコピー」で、その URL をコピーできます。

## ローカライズ

画面の文字列はコードに英語で `loc("…")` と書き、訳は [Ommateum/Localizable.xcstrings](Ommateum/Localizable.xcstrings) に置きます。文字列を足すときは、英語の文で `loc` を呼び、カタログに日本語訳を加えます。値を埋め込む文は `%@` / `%ld` を使い、訳では `%1$@` で語順を入れ替えられます。

## 配布用ビルド

```sh
scripts/release.sh                                  # ad-hoc 署名（この Mac 用）
OMMATEUM_BUNDLE_ID=... DEVELOPER_ID="Developer ID Application: ..." NOTARY_PROFILE=... scripts/release.sh
```

## カスタムアクション

右クリックメニューに、自分用のコマンド（スクリプト、ショートカット、共有サービス）を追加できます。
ファイル ▸ アクション ▸ アクションを編集… で `actions.json` を開きます。書式は [docs/actions.md](docs/actions.md) を参照してください。
